---
title: Server Logs
---

The Server Logs section allows administrators to browse application logs directly from the admin panel. This requires filesystem log storage to be enabled.

## Features

- **Browse logs** — View application logs with timestamps and log levels
- **Filter by level** — Filter logs by severity: `error`, `warn`, `info`, `debug`, `verbose`
- **Search** — Search through log entries

## Configuration

See [Server Settings — Logging](/docs/self-hosted/settings/server-settings/#logging) for the related settings.
