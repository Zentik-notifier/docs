---
title: Server Files
---

The Server Files section allows administrators to manage files stored on the backend server. This is primarily used for uploading and managing configuration files such as APN private keys for push notification providers.

## Features

- **Browse files** — View files stored in the server files directory
- **Upload** — Upload new files (e.g. `.p8` APN key files)
- **Delete** — Remove files from the server

## Configuration

See [Server Settings — Server Files](/docs/self-hosted/settings/server-settings/#server-files) for the related settings.
