---
title: Backup Management
---

The Backup Management section allows administrators to view, create, download, and restore database backups.

## Features

- **View backups** — Browse existing backup files with their size and creation date
- **Create backup** — Trigger a manual database backup
- **Download** — Download a backup file to your device
- **Restore** — Restore the database from a selected backup
- **Delete** — Remove old backup files

## Configuration

See [Server Settings — Database Backup](/docs/self-hosted/settings/server-settings/#database-backup) for the related settings.
