---
title: Changelog
---

The Changelog section allows administrators to manage changelog entries that are displayed to users when the app is updated.

Zentik can fetch changelogs from a remote server or serve entries stored in the local database. By default, changelogs are proxied from the official Zentik backend.

## Configuration

See [Server Settings — Changelog](/docs/self-hosted/settings/server-settings/#changelog) for the related settings.
